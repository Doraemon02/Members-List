Members List Bot（以下簡稱「本機器人」、「本服務」、「我們」）重視使用者的隱私及個人資料安全。

本隱私權政策旨在說明本服務如何收集、使用、儲存、處理、分享及保護使用者相關資料，以及使用者在資料處理過程中可能享有的權利。

本政策適用於：

  • 使用 Members List Bot 的 Discord 使用者。
  • 邀請本機器人加入伺服器的管理者。
  • 被加入名單的 Discord 成員。
  • 使用本機器人備份及自動化功能的使用者。
  • 訪問本服務官方網站及 API 的訪客。

當您使用本服務，即表示您已閱讀本政策。

若您不同意本政策，請停止使用相關功能，並聯絡伺服器管理者或本服務管理者處理相關資料。

第一條：資料處理者及責任區分

1.1 本服務管理者

本機器人由 Members List Bot 的服務管理者維護及營運。

本服務管理者負責：

  • 維護機器人程式。
  • 管理機器人資料庫。
  • 維護相關 API。
  • 處理服務安全問題。
  • 管理本機器人的全域黑名單。
  • 處理使用者對本服務提出的相關請求。

正式公開前，應補充實際營運者名稱及有效聯絡方式。

1.2 Discord 伺服器管理者

伺服器管理者可以透過本機器人建立、修改、刪除及管理伺服器名單。

伺服器管理者對其主動提交及管理的成員資料，應負有適當的管理責任。

1.3 資料責任區分

本服務管理者及 Discord 伺服器管理者可能具有不同的資料處理責任。

例如：

  • 本服務管理者負責維護機器人及其資料庫。
  • 伺服器管理者負責決定名單內容及相關管理用途。
  • Discord 負責其平台本身的資料處理。
  • Roblox 負責其平台 API 及帳號資料。

各方責任應依實際控制範圍及適用法律判斷。

第二條：我們收集哪些資料

本服務可能依照使用者所使用的功能，處理以下資料。

2.1 Discord 帳號識別資料

可能包括：

  • Discord 使用者 ID。
  • Discord 伺服器 ID。
  • Discord 伺服器名稱。
  • Discord 頻道 ID。
  • Discord 訊息 ID。
  • Discord 身分組 ID。
  • Discord 使用者在伺服器中的顯示名稱。
  • Discord 成員相關識別資料。

其中，Discord 使用者 ID 主要用於識別名單中的指定成員及執行相關管理操作。

當管理者使用 Roblox 名單功能時，本服務可能處理：

  • Roblox 使用者名稱。
  • Roblox 顯示名稱。
  • 使用者名稱與 Discord 使用者 ID 之間的名單對應關係。
  • 管理者輸入的 Roblox 相關查詢資料。

本服務目前使用 Roblox 公開 API：

https://users.roblox.com/v1/usernames/users

查詢使用者名稱對應的公開顯示名稱。

本服務不會因為提供此項查詢功能，就代表取得使用者的 Roblox 密碼、登入憑證或私人帳號存取權限。

2.3 名單及自訂資料

當使用者或伺服器管理者使用名單管理功能時，可能保存：

  • 名單名稱。
  • 名單編號。
  • 名單內的 Discord 使用者 ID。
  • Roblox 使用者名稱。
  • 自訂文字。

  • 名單發布頻道 ID。
  • 名單訊息 ID。
  • 名單 UI 顯示設定。

上述資料主要用於建立、顯示、修改、查詢及更新伺服器名單。

2.4 伺服器設定資料

為提供正常的機器人服務，本服務可能保存：

  • Discord 伺服器 ID。
  • 管理者設定的權限角色 ID。
  • 通知頻道 ID。

  • 其他還原名單所需的資料。

備份資料可能包含原始名單中的部分或全部資訊，具體以備份功能實際保存的欄位為準。

2.6 全域黑名單資料

本服務可能保存被列入全域黑名單的使用者資料，包括：

  • Discord 使用者 ID。
  • 黑名單原因。

上述資料用於判斷使用者是否受到本機器人的服務限制。

當符合條件的使用者嘗試加入相關伺服器時，本機器人可能執行預先設定的限制措施，並向相關伺服器管理者傳送通知。

2.7 自動禁言系統資料

本服務可能透過本地 JSON 檔案保存：

  • Discord 伺服器 ID。
  • 自動禁言頻道 ID。

上述資料用於識別啟用自動禁言功能的頻道。

2.8 成員統計系統資料

本服務可能透過本地 JSON 檔案保存：

  • Discord 伺服器 ID。
  • 統計模式。
  • 統計分類 ID。
  • 統計頻道 ID。

本服務亦可能讀取 Discord 提供的成員統計及狀態資訊，用於更新統計頻道。

統計項目可能包括：

  • 伺服器總人數。
  • 一般成員人數。
  • 機器人人數。
  • 線上人數。
  • 閒置人數。
  • 請勿打擾狀態人數。

相關統計可能以群體數量形式顯示。

2.9 網站及 API 公開資訊

本服務的網站 API 可能讀取並提供：

  • 機器人運作狀態。
  • 機器人延遲。
  • 機器人運作時間。
  • 已加入伺服器數量。
  • 可取得的伺服器成員數量。
  • Discord 伺服器 ID。
  • Discord 伺服器名稱。
  • Discord 伺服器圖示。
  • Discord 伺服器邀請連結。

上述資訊可能被網站前端或其他取得 API 存取權的訪客讀取。

特別是伺服器邀請連結，可能使網站訪客直接進入相關 Discord 伺服器。

伺服器管理者應在使用本服務前了解此項資訊公開情況。

2.10 指令及訊息內容

本機器人可能讀取使用者輸入的 Discord 訊息，以識別及執行相關前綴指令。

例如：

  • `.find`
  • `.new`
  • `.add`
  • `.edit`
  • `.remove`
  • `.timeout`
  • `.ban`
  • `.kick`
  • `.help`

部分功能亦可能讀取管理者在指定頻道輸入的文字，例如名單標題或相關自訂內容。

本服務會依照功能需要處理相關輸入。

本政策不代表本服務會全面保存 Discord 伺服器中的所有聊天訊息。

但是，部分管理操作可能直接讀取或刪除指定頻道中的訊息。
