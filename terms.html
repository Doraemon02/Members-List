歡迎使用 Members List Bot（以下簡稱「本機器人」、「本服務」或「我們」）。

本服務是一款以 Discord 平台為基礎的伺服器名單管理、自動化管理，旨在協助 Discord 伺服器管理者管理成員名單、Roblox 帳號資料、自動更新名單、管理伺服器設定及執行相關管理功能。

在邀請、安裝、使用或透過其他方式存取本服務之前，請先仔細閱讀本服務條款。

當您邀請本機器人加入 Discord 伺服器、使用任何指令、操作管理面板或使用本服務提供的其他功能時，即表示您已閱讀、理解並同意遵守本服務條款及相關隱私權政策。

若您不同意本條款的任何內容，請停止使用本服務，並將本機器人從您的 Discord 伺服器移除。

第一條：定義與適用範圍

1.1 定義

本條款中使用以下名詞：

  1. 本機器人（Bot）： 指 Members List Bot，包括其 Discord 機器人帳號、指令、互動介面、管理面板、自動化功能及相關服務。
  2. 使用者： 指任何透過 Discord 使用、操作或與本機器人互動的自然人。
  3. 伺服器管理者： 指擁有 Discord 伺服器管理權限，或經伺服器管理者授權操作本機器人的使用者。
  4. 伺服器： 指 Discord 平台上的任何社群、群組或伺服器。
  5. 名單資料： 指使用本機器人建立、修改、保存或管理的群組名稱、成員資料、Roblox 使用者名稱、自訂文字及其他相關資訊。
  6. 備份資料： 指透過本機器人備份功能產生並儲存的名單及相關設定。
  7. 第三方服務： 指 Discord、Supabase、Roblox 及其他提供本服務所需技術、資料或基礎設施的外部平台。
  8. 管理功能： 指禁言、停權、踢出、自動身分組管理、訊息清理及其他伺服器管理操作。

1.2 適用範圍

本條款適用於：

  • Discord 伺服器管理者。
  • 一般 Discord 伺服器成員。
  • 使用本機器人指令的使用者。
  • 使用本機器人網站及公開 API 的訪客。
  • 使用備份、名單管理及自動化功能的相關人員。

1.3 第三方平台規範

本服務運行於 Discord 平台，並可能使用其他第三方平台提供的功能。

使用者仍須遵守 Discord、Roblox、Supabase 及其他相關平台的服務條款、社群規範及適用政策。

本條款不得解釋為取代第三方平台的使用規範。

第二條：服務內容與功能

本機器人目前提供或可能提供以下功能：

2.1 名單管理系統

使用者可透過相關指令：

  • 建立及刪除名單。
  • 設定名單名稱。
  • 新增 Discord 成員至指定名單。
  • 編輯名單中的成員資料。
  • 移除指定成員。
  • 新增 Roblox 使用者名稱。
  • 設定自訂文字。
  • 設定成員顯示表情符號。
  • 搜尋及查詢名單中的 Roblox 使用者名稱。
  • 設定名單顯示方式。
  • 設定名單分隔線及標題。

使用者必須確保所輸入的資料合法、正確，且具有適當的使用及處理權限。

2.2 Roblox 資料查詢

本服務可使用 Roblox 提供的公開使用者名稱查詢 API，查詢使用者名稱所對應的顯示名稱。

查詢結果可能受到以下因素影響：

  • Roblox API 的可用性。
  • Roblox 服務維護。
  • 使用者名稱變更。
  • Roblox 平台資料更新。
  • 第三方服務回應延遲或錯誤。

本服務不保證 Roblox 資料永遠正確、即時或完整。

本服務亦不代表 Roblox 官方，也不對 Roblox 平台的資料及服務負責。

2.3 自動更新系統

本服務可依照伺服器管理者設定，每日自動更新指定名單。

自動更新可能包含：

  • 重新查詢 Roblox 顯示名稱。
  • 更新 Discord 頻道中的名單訊息。
  • 依照指定關鍵字檢查 Roblox 顯示名稱。
  • 根據設定新增或移除 Discord 身分組。
  • 發送更新成功或失敗通知。

管理者應確認機器人具有執行相關操作所需的 Discord 權限。

2.4 身分組管理

若管理者設定自動身分組功能，本服務可能依照名單設定及 Roblox 顯示名稱中的指定關鍵字，自動為 Discord 成員新增或移除指定身分組。

管理者應自行確認：

  • 指定身分組是否正確。
  • 關鍵字是否符合預期。
  • 機器人角色的層級是否足夠。
  • 自動身分組操作是否符合伺服器規範。

本服務不對錯誤設定所造成的身分組變更承擔無條件責任。

2.5 備份與還原系統

本服務提供名單備份功能，管理者可建立備份並取得備份碼。

備份可能包含：

  • 名單名稱。
  • Roblox 使用者名稱。
  • Discord 使用者 ID。
  • 自訂文字。
  • 名單相關設定。
  • 指定身分組 ID。
  • 其他與名單還原相關的資料。

備份碼應由管理者妥善保管。

任何取得有效備份碼的人士，都可能在符合系統操作條件的情況下使用相關備份功能。

請勿將備份碼公開分享給不可信任的人士。

本服務不保證所有備份永久保存，也不保證任何時間均能成功還原。

2.6 伺服器管理功能

本服務可能提供：

  • 成員禁言。
  • 成員停權。
  • 成員踢出。
  • 大量刪除訊息。
  • 指定頻道自動禁言。
  • 管理權限設定。
  • 管理面板操作。

上述功能可能直接影響 Discord 伺服器成員的使用權限及訊息內容。

使用者必須確認自己具有適當權限，並遵守 Discord 規範及適用法律。

2.7 伺服器成員統計

本服務可建立伺服器統計分類及語音頻道，顯示：

  • 伺服器總人數。
  • 一般成員人數。
  • 機器人人數。
  • 線上成員人數。
  • 閒置成員人數。
  • 請勿打擾狀態成員人數。

相關數據可能隨 Discord 伺服器成員狀態變化而更新。

統計結果僅供管理及參考，不保證與 Discord 官方統計在所有時間完全一致。

2.8 網站及 API

本服務可能提供官方網站及公開 API，用於展示機器人運作資訊。

目前網站 API 可能公開以下資訊：

  • 機器人上線狀態。
  • 機器人延遲。
  • 運作時間。
  • 已加入伺服器數量。
  • 可取得的伺服器成員總數。
  • 伺服器名稱。
  • 伺服器圖示。
  • 伺服器邀請連結。

使用者及伺服器管理者應理解，相關資訊可能透過公開 API 提供給網站訪客。
